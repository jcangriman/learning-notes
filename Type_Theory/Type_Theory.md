Concepts: 
33. **Untyped Lambda Calculus** — functions as primitive objects, substitution, beta reduction
34. **Simply Typed Lambda Calculus** — adding types to lambda calculus, type checking, function types $A \rightarrow B$
35. **Product & Sum Types** — $A \times B$ (pairs) and $A + B$ (either/or), corresponding to $\land$ and $\lor$
36. **Unit & Empty Types** — types corresponding to $\top$ (truth) and $\bot$ (falsehood)
37. **The Curry-Howard Correspondence** — propositions as types, proofs as programs, the bridge between logic and computation
38. **Dependent Types** — types that depend on values, $\Pi$-types and $\Sigma$-types
39. **Universe Hierarchies** — $\text{Type}_0$, $\text{Type}_1$, ... avoiding paradoxes
40. **Inductive Types** — defining types by their constructors, natural numbers as an example
41. **Identity Types** — what it means for two terms to be equal in type theory
42. **The Calculus of Constructions** — a formal system unifying types, terms, and proofs
43. **The Calculus of Inductive Constructions (CIC)** — adding inductive types, Lean's actual foundation
